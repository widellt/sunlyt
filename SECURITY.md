# Security

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Don't open a public issue for them.

Also report privately, rather than in an issue or pull request:

- any file or text in this repository that looks like real mission data (trajectories, schedules, vehicle details), and
- anything that should not be public for another reason.

sunlyt reads trajectory files you supply and never sends them anywhere. Keep your own mission data out of issues, pull requests and screenshots; the synthetic trajectory from `sunlyt synth` reproduces most problems.
